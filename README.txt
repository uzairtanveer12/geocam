1. Create a new GitHub repository and upload everything in this folder (keep the .github folder).
2. Open the Actions tab, run "Build APK" (it also runs on every upload). Takes about 5 minutes.
3. Open the finished run, download the "GeoCam-apk" artifact, unzip it, send app-debug.apk to your phone and install it.
4. On first open, allow Camera and Location.
